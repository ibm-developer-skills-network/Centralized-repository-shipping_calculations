# Shipping Calculator Documentation

## Overview
The Shipping Cost Calculator calculates shipping costs based on package weight and shipping rate.

## Requirements
- Python 3

## How to Run
Execute the following command:

python3 Shipping_Cost_Calculator.py

## How It Works
1. Enter the package weight in kilograms.
2. Enter the shipping rate per kilogram.
3. The application calculates the shipping cost.
4. The result is displayed in USD.

## Input Validation
The application checks that package weight and shipping rate are greater than zero.
